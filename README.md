RUS MESSANGER - JavaFX Maven шаблон
----------------------------------

Сборка и запуск:
- Требуется JDK 17+.
- mvn clean javafx:run

SMTP (отправка почты):
- Установите переменные окружения:
  SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS
  Например для Gmail (требуется App Password и включённый TLS):
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=587
- EmailService.sendVerificationCode отправит код на указанный email.

ИИ-помощник:
- По умолчанию используется локальная симуляция.
- Для интеграции с реальным API раскомментируйте код и добавьте HTTP вызов в AIService (OpenAI/Meta/локальный LLM).
